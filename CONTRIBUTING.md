# Contribuindo

Contribuições são bem-vindas. Antes de enviar uma alteração:

1. descreva o problema e a plataforma afetada;
2. mantenha a interface integralmente dark e com contraste adequado;
3. não inclua modelos GGUF, binários, tokens ou configurações pessoais;
4. compile o projeto correspondente em modo Release;
5. teste o fluxo coordenador/worker quando alterar processos ou rede.

Em relatórios de bug, inclua sistema operacional, arquitetura, GPU, memória,
versão do driver e trecho mínimo do log sem informações sensíveis.
